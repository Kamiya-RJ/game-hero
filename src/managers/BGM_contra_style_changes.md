# 冒险小勇士 BGM 魂斗罗风格改动说明

## 改动文件

- `SoundManager.js` — 重写 `_scheduleBGM()`

---

## 设计思路

原版魂斗罗 BGM 有版权，本次改写为**风格相近的原创曲**，保留以下核心特征：

- 军队进行曲节奏，稳健有力
- D 大调，明亮但不失紧迫感
- 标志性切分节奏 + 强力低音线
- NES 芯片风音色（square + triangle 双音轨）

---

## 曲目结构（约 28 秒一循环）

| 段落  | 特点 |
|-------|------|
| Intro  | 4 拍鼓点引入，铺垫进场感，让节奏先建立 |
| A      | 主题句：D 大调进行曲上行旋律，五度大跳，刚劲有力 |
| A'     | 主题重复：加入切分十六分音符装饰，节奏更紧迫 |
| B      | 副歌：跳至高音区大跳，英雄感爆棚 |
| C      | 过渡句：全音阶下行后反向爬升，蓄力铺垫 |
| A''    | 主题高八度重复：全速冲刺，最强力度 |
| Outro  | 收尾回落，英雄姿态落地，无缝引回 Intro |

---

## 四层音色

| 层次       | 波形                    | 作用 |
|------------|-------------------------|------|
| 主旋律层   | `square`                | NES 经典芯片音色，留 15% 间隙增加颗粒感 |
| 对位声部   | `triangle`              | 仅 B段 + A''段，旋律三度下方跟随，NES 第二音轨做法 |
| 低音线     | `triangle`              | 进行曲步伐律动（D→A→G→A），八度加厚，音量最大（0.10） |
| 打击层     | `sawtooth` + `square`   | 底鼓每拍 + 军鼓 snare 第二拍 + 踩镲每半拍 |

---

## 调性与和声

- **调性**：D 大调（D E F# G A B C# D）
- **低音进行**：D → A → G → A 循环（强-弱-强-弱，进行曲步伐特征）
- **对位声部**：小三度下方（×0.7937，即 ÷2^(4/12)）

---

## 打击节奏型（每两拍一循环）

```
拍位：  1       1.5     2       2.5
底鼓：  ●               ●
军鼓：                  ●
踩镲：          ●               ●
```

标准进行曲鼓组：底鼓在强拍，军鼓 snare 在弱拍（第二拍），踩镲填充半拍。

---

## BPM

**160**，比上一版紧张 BGM（150）稍快，但节奏型是进行曲风格，听感更稳健而非慌乱。

---

## 与上一版（紧张小调 BGM）的对比

| 项目       | 紧张版（Am）              | 本版（魂斗罗风格，D大调）     |
|------------|---------------------------|-------------------------------|
| 调性       | A 自然小调 + 和声小调     | D 大调                        |
| 情绪       | 阴暗、不安、压迫          | 刚劲、英雄、紧迫              |
| BPM        | 150                       | 160                           |
| 低音风格   | ostinato 律动低音         | 进行曲步伐（强-弱）           |
| 特殊技巧   | 不和谐叠音（降半音摩擦）  | NES 双音轨对位声部            |
| 打击底鼓   | 每半拍（密集）            | 每一拍（稳健）                |
