# 冒险小勇士 BGM 紧张风格改动说明

## 改动文件

- `SoundManager.js` — 重写 `_scheduleBGM()`

---

## 设计思路

### 调性
- **A 自然小调 + 和声小调**（加入 G# 导音）
- 小调天生带暗色，导音制造强烈的解决欲望但始终不给解决——维持持续紧张感

### BPM
- 由原来的 120 提升至 **150**，节奏更急促

---

## 曲目结构（约 18 秒一循环）

| 段落  | 特点 |
|-------|------|
| Intro | 切分低音节奏，奠定不安气氛 |
| A     | 急促下行旋律，减音程制造不稳定感 |
| B     | 半音阶上行爬升，压迫感逐步增强 |
| A'    | 主题高两个八度重复，音色更尖锐密集 |
| C     | 危机顶点：密集切分 + 大跳 + 不和谐叠音 |
| Outro | 下行但不解决，情绪悬空，引回循环 |

---

## 四层音色

| 层次     | 波形       | 作用 |
|----------|------------|------|
| 旋律层   | `square`   | 主旋律，保留芯片感，音符间距更紧，留 15% 间隙增加颗粒感 |
| 暗影层   | `sawtooth` | 仅 C 段（危机顶点）叠加降半音（×0.9439），制造轻微不和谐摩擦 |
| 低音律动层 | `triangle` | 持续 ostinato 低音，Am→G→F→E 小调下行循环，八度加厚 |
| 打击层   | `sawtooth` + `square` | 底鼓每半拍一次（比原来快一倍）+ 弱拍踩镲 + 每两拍 snare 重音 |

---

## 和弦进行

低音层采用经典小调下行进行，循环铺满全曲：

```
Am → G → F → E
```

E 为和声小调导音和弦，进一步加强紧张感。

---

## 关键技术细节

### 减音程
A 段旋律中使用减五度（如 A→Eb）跳跃，这是西方音乐中最具不稳定感的音程，俗称"魔鬼音程"。

### 半音阶爬升（B 段）
```
A → A# → B → C → C# → D → D# → E → F → F# → G → G#
```
每个半音都比上一个更紧张，听感上像是压力不断累积。

### 不和谐叠音（C 段暗影层）
在危机顶点将旋律音降半音后叠加，产生小二度摩擦（最强的不协和音程），音量控制在 0.02（极低）保证不刺耳但有效果。

### 打击节奏对比

| 版本 | 底鼓频率 | 踩镲 | Snare |
|------|----------|------|-------|
| 原版（欢快） | 每两拍   | 弱拍 | 无 |
| 新版（紧张） | 每半拍   | 弱拍 | 每两拍强音 |
