# Changelog

## 2026-05-23

### 🐛 Bug Fixes

- **修复移动平台创建时的 `body[key] is not a function` 报错**
  - `MovingPlatform` 已在构造函数中通过 `scene.physics.add.existing(this, true)` 添加了静态物理体，再次通过 `physics.add.group().add()` 添加会触发 Phaser 内部不兼容操作
  - `GameScene.js` 中将 `movingPlatforms` 从 `physics.add.group()` 改为普通数组 `[]`，碰撞检测改为 `forEach` 逐个添加
  - 修复了 `createColliders` 中重复解构和重复添加碰撞器的问题

- **修复移动平台 static body 调用 `reset()` 报错**
  - `MovingPlatform.js` 中 `onUpdate` 回调里 `this.body.reset()` 是动态物理体方法，静态物理体不支持
  - 改为直接设置 `this.body.position.x` 和 `this.body.position.y`

- **修复玩家站在移动平台上不跟随移动**
  - `MovingPlatform` 原使用 static body + tween 改坐标，Phaser 碰撞系统不会在静态物理体间传递速度
  - 改为 dynamic body + `setImmovable(true)` + `setAllowGravity(false)`，用 `setVelocityX/Y` 驱动移动
  - `GameScene.js` 的 `update()` 中添加 `movingPlatforms.forEach(mp => mp.update())` 调用

- **修复玩家站在平台边缘悬空过多的问题**
  - `Player.js` 中设置自定义碰撞体尺寸：`setSize(10, 26)` + `setOffset(11, 6)`
  - 宽度缩到 10px 使边缘更敏感，高度 26px 留底部 6px 空隙，同时保证头顶能正常碰撞平台
  - 解决了站在边缘整个身子悬空不掉落、以及从下方跳跃穿过平台的问题

- **修复刺猬朝向错误**
  - `Hedgehog.js` 中素材默认朝左，`setFlipX` 逻辑修正为 `this.direction === 1` 时翻转（向右走时翻转素材）

### ✨ Improvements

- **移动平台支持自定义颜色**
  - `GameScene.js` 的 `createMovingPlatforms` 中添加 `mpColor` 默认橙色 `0xffaa00`
  - 支持通过 `levels.js` 配置中的 `color` 字段自定义每个平台颜色

- **云朵透明度优化**
  - `GameScene.js` 的 `_createClouds` 中大椭圆 alpha 改为 `1`（完全不透明），小椭圆改为 `0.85`
  - 解决了三个椭圆叠加痕迹可见的问题，大云朵更实，小云朵保持柔和边缘

- **敌人行为随机化**
  - `Slime.js`：初始方向随机、每个实例独立随机速度（0.7~1.3 倍 SLIME_SPEED）
  - `Hedgehog.js`：初始方向随机、速度随机、出刺初始延迟随机（`Phaser.Math.Between(0, HEDGEHOG_SPIKE_INTERVAL)`）
  - 避免了所有敌人移动同步的问题

### 📝 Code Quality

- 所有修改保留了原有注释，仅在改动处添加或修改注释
